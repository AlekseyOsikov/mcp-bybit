# Proposal

## Why

Сейчас нет MCP-сервера, который давал бы ИИ-агенту доступ только для чтения к спотовым рыночным данным биржи Bybit (поиск торговых пар, текущая цена, история цен и производная аналитика) — по аналогии с тем, как `mcp-moex` делает это для Московской биржи. Агенту, которому нужно ответить на вопрос о цене криптовалюты на Bybit, сейчас неоткуда получить структурированные и проверяемые данные.

## What Changes

- Добавить новый MCP-сервер (`mcp-bybit`), работающий с публичным Bybit v5 REST API (`https://api.bybit.com`), только категория `spot`, без API-ключей и без приватных/торговых эндпоинтов.
- Добавить `search_symbols`: поиск торгуемых спотовых пар по базовой/котируемой монете или подстроке тикера (без названий компаний и ISIN — у крипты нет такого понятия; например, `ETH` находит `ETHUSDT`, `ETHUSDC`, `ETHBTC`).
- Добавить `get_current_price`: тикер спотовой пары в реальном времени (последняя цена, лучшие бид/аск, изменение/максимум/минимум за 24 часа, объём/оборот за 24 часа), `price_unit` — котируемая монета пары.
- Добавить `get_price_history`: OHLCV-свечи по спотовой паре за период и интервал с готовой сводкой (начало, конец, минимум, максимум, изменение), по аналогии с `get_price_history` из `mcp-moex`, но с интервалами и пагинацией Bybit.
- Добавить `compute_price_metrics`, `compare_with_benchmark`, `compare_securities`: серверная аналитика (волатильность, просадки, корреляция, бета), считается только по уже полученной истории (`get_price_history`), без обращений к бирже — перенос движка аналитики из `mcp-moex`. `compare_with_benchmark` и `compare_securities` дополнительно отклоняют сравнение историй с разной котируемой монетой (`price_unit`).
- Все шесть инструментов помечены только читающими (`readOnlyHint = true`); сервер не публикует никаких инструментов записи/торговли/аккаунта и не требует ключей.
- Вне рамок этого изменения (для будущих изменений): категории деривативов (linear/inverse/option), funding rate и open interest, стакан и лента сделок, режим расписания (watch, SQLite).

## Capabilities

### New Capabilities
- `mcp-server-runtime`: регистрация шести инструментов, схемы параметров, формат результатов и ошибок, запуск и проверка сервера.
- `bybit-symbol-search`: поиск торгуемых спотовых пар Bybit по монете или подстроке тикера.
- `bybit-current-price`: снимок цены/тикера в реальном времени по спотовой паре Bybit.
- `bybit-price-history`: история OHLCV-свечей и сводка по периоду для спотовой пары Bybit.
- `bybit-price-analytics`: метрики, сравнение с эталоном и сравнение пар между собой по уже полученной истории цен, без дополнительных обращений к сети.

### Modified Capabilities
(нет — проект новый, существующих спек ещё нет)

## Impact

- Новый Python-пакет `mcp_bybit` (структура по аналогии с `mcp-moex`: `src/mcp_bybit/`, `tests/`, `pyproject.toml`, `scripts/smoke_client.py`).
- Новая внешняя зависимость: публичный Bybit REST API v5 (без аутентификации). Тот же стек, что у `mcp-moex`: `mcp`, `httpx`, `pydantic`.
- На другие проекты влияния нет; это отдельный репозиторий (`mcp-bybit`), сейчас содержащий только служебные файлы OpenSpec.
