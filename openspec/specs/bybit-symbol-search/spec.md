# bybit-symbol-search Specification

## Purpose

Позволяет агенту найти торгуемую спотовую пару на Bybit по монете или части тикера и получить канонический `symbol` для остальных инструментов, не угадывая точное написание тикера по памяти.

## Requirements

### Requirement: Поиск торговой пары
Инструмент `search_symbols` SHALL принимать параметры `query` (непустая строка: тикер пары целиком или его часть, либо код монеты, регистр не учитывается) и `limit` (целое от 1 до 20; по умолчанию 10) и возвращать список найденных спотовых пар. Совпадение SHALL проверяться по подстроке в `symbol`, `baseCoin` или `quoteCoin`. Каждый элемент результата MUST содержать `symbol` (в каноническом верхнем регистре), `base_coin`, `quote_coin` и `status`. Результат MUST содержать `count` и признак `truncated`.

#### Scenario: Поиск по коду монеты
- **WHEN** агент вызывает `search_symbols` с `query = "eth"`
- **THEN** среди результатов есть `ETHUSDT`
- **AND** у каждого результата `base_coin = "ETH"` или `quote_coin = "ETH"`

#### Scenario: Поиск по полному тикеру
- **WHEN** агент вызывает `search_symbols` с `query = "BTCUSDT"`
- **THEN** первым элементом результата является пара с `symbol = "BTCUSDT"`

#### Scenario: Пустой запрос
- **WHEN** агент вызывает `search_symbols` с пустым или состоящим из пробелов `query`
- **THEN** вызов завершается ошибкой валидации

#### Scenario: Слишком много совпадений
- **WHEN** число подходящих пар больше `limit`
- **THEN** результат содержит не более `limit` элементов
- **AND** `truncated = true`, а `count` равен полному числу найденных совпадений

### Requirement: Только торгуемые пары
Результаты поиска SHALL включать только пары со статусом `Trading` на Bybit. Приостановленные, делистнутые и ещё не запущенные пары MUST NOT попадать в результат.

#### Scenario: Делистнутая пара
- **WHEN** среди совпадений по подстроке есть пара не в статусе `Trading`
- **THEN** эта пара отсутствует в результате поиска

### Requirement: Только категория spot
Инструмент SHALL искать пары только среди спотовых инструментов Bybit (категория `spot`). Инструменты деривативов (linear, inverse, option) MUST NOT возвращаться.

#### Scenario: Совпадение существует только среди деривативов
- **WHEN** `query` совпадает с тикером, который торгуется только в категориях linear/inverse/option и отсутствует в spot
- **THEN** результат поиска не содержит этот тикер
